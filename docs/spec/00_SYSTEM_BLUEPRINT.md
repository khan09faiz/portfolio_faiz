# System Blueprint

Purpose:
Describe the complete product ecosystem.

Core Modules:
- Public Portfolio
- Hidden Admin CMS
- Content Database
- Asset Library
- Resume Studio
- Job Hunt
- AI/RAG Layer
- GitHub Sync
- LinkedIn PDF Import
- Public Chatbot
- Theme System

High-Level Flow:
Admin -> CMS -> Database -> Frontend
Uploads -> Parser -> Database -> AI Knowledge Base
GitHub -> Sync -> Cache -> CMS
LinkedIn PDF -> Parser -> Structured Data -> CMS
Visitor -> Portfolio -> Public Chatbot -> RAG -> Answer
Resume Studio -> AI -> PDF/DOCX Export
